## 简介

这是一份面向合工大学生的生活指南，最初主要针对**宣城校区**编写，目前也在持续完善**合肥校区**相关内容。

我们希望通过更系统、更易检索的方式，把校园学习、生活、办事与常见问题汇总成一个可靠的入口。

网站内大部分页面都有严谨的引用来源标注，完全无广，纯为爱发电，可安心食用。

> [!warning]
> 这**不是**合肥工业大学的官方文档。
>
> 此文档目前主要由学生维护，所有内容均不代表校方官方观点和意见。因更新滞后或其他问题，部分内容可能与实际情况存在出入，请以学校发布的相关管理办法为准

### 你能在这里找到

- 新生必看与常见问答
- 校园设施、交通与生活服务
- 学习与考试相关流程
- 组织、活动与校园文化
- 联系方式与实用黄页
- ……

## 贡献 / 参与方式

目前的问题主要是维护者较少，而且肥区那边的资料缺失了很多，在此希望有相关能力的同学能帮忙一起编写文档，让这份爱传承下去🥺🥺无论是简单一点的错别字纠错还是更新文档，我们都非常欢迎❤️🫶

详见➡️[参与进来](https://survive-hfut.github.io/about/contribute)

如果觉得这个网站对你有帮助的话也欢迎点个 Star 鼓励一下我们
