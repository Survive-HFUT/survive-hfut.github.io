# 宅基地

宅基地是合肥校区的 ACG 协会，下设 COS 部、宅舞部、音乐部、同人部、未名组和编辑部

:::info

以下部门介绍均为[宅基地官网](https://acgzjd.cn/2026/04/10/departments/)原文[^1]

## 部门

### COS 部

这里是宅基地下属部门 cos 部 (◦˙▽˙◦)

我们致力于提供一个平台让对 cos/漫展感兴趣的米娜都能够参与其中。

我们会参加合肥每一次大型的漫展，有自己的摊位提供无料和物资，有摄影老师帮米娜拍好看的照片或者低脂小视频（）我们还会策划剧组团片去拍外景一起玩哦。

在这里我们不是所谓的“现充”，只是为了努力还原自己喜欢的角色，或是感受漫展特有的包容与热情的氛围，无论你对 cosplay 是否了解，我们都欢迎你的到来ヾ(✿ﾟ▽ﾟ)ノ

群号：`712515574`

### 编辑部

这里是宅基地下属部门编辑部 ヾ(≧▽≦\*)o

无论你是热爱码字写文还是对排版、网站运营感兴趣，编辑部都非常欢迎你的到来！

我们编辑部平时主要负责：记录社团的各种大小活动，撰写 ACG 相关的推文、游戏/番剧安利，以及各种脑洞大开的整活策划📝
