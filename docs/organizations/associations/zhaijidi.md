# 宅基地

宅基地是合肥校区的 ACG 协会，下设 COS 部、宅舞部、音乐部、同人部、未名组和编辑部，日常活动以漫展参展、舞台演出、绘画创作和线上交流为主

各部门均表示没有相关经验也可以参加

:::info

本页整理自[宅基地官网](https://acgzjd.cn/)，群号和活动安排可能变动，以官网为准

:::

## 部门

### COS 部

参加合肥各大漫展，为社员提供摊位和物资，安排摄影师跟拍，也会策划剧组的外景拍摄。不要求提前了解 cosplay 相关知识

群号：`712515574`

### 宅舞部

每年的固定活动包括与中科大的快闪、科大动漫之夜、安农大动漫之夜等。可以在群内找同好一起录舞，或参加漫展演出

群号：`107973969`

### 音乐部

讨论音乐、组建乐队、交流编曲，不限于 ACG 曲目

群号：`961220262`

### 同人部

以线上绘画活动为主，新人较多时会在周日至周四晚间组织速写，也会不定期举办击鼓传画、绘画教室等活动。群内有学长可以解答绘画问题

群号：`823504597`

### 未名组

即 WOTA 艺，每学期出企划并参加现场演出。新区周例为每周一至周四 21:00—22:00，在体育馆后活动

群号：`305897495`

### 编辑部

记录社团活动，撰写 ACG 推文和番剧安利，负责排版与网站运营，也欢迎对建站技术感兴趣的同学

群号：`1053028707`
