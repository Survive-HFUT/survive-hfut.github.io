# 合工大航模队

:::info

以下内容摘自[合工大航模队团队介绍](https://mp.weixin.qq.com/s/1-TbM4OA96ueExYihS2IJg)，招新联系方式和更多细节详见原文

:::

HFUTAMT，全称合肥工业大学航模队。成立于 2013 年，隶属机械学院、由李德宝老师和祖磊书记专职指导，搭建完整年级梯队，分结构、气动、设计、电控、试飞全研发方向常年征战 CADC 与 CUADC 全国大学生飞行器设计创新大赛等航空航天类赛事，多次斩获包括全国一、二等奖等多个奖项。队内形成完整新生培养体系，兼顾科学竞赛、校内航空科普与飞行器创新实践，是校内深耕航空飞行器研发的核心科创团队。
