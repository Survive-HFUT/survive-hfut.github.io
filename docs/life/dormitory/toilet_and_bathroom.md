# 卫生间 & 浴室

三校区宿舍均**无独立卫浴**，但有公共卫生间和浴室

## 分布

:::tabs key:campus

== 屯溪路校区

- 浴室：位于学生宿舍 10 号楼和 11 号楼之间，明园餐厅附近。

- 卫生间：宿舍每层楼的两侧均有公共卫生间。

== 翡翠湖校区

- 浴室：位于每栋宿舍的 1 楼走廊尽头

- 卫生间：每间宿舍有一个独立卫生间，同时宿舍每层有公共卫生间。

== 宣城校区

- 北区
  - 位于东西两侧楼梯口旁边
- 南区
  - 位于每层两头和中间，其中中间位置只有卫生间，无浴室

:::

## 浴室

[[./bathroom.jpg|宣区浴室]]

宣区的每个浴室有四个淋浴间，目前已于 2024 年 12 月前改造完成[^1]。与旧的浴室相比，新的浴室内设有储物柜、暖气片和休息凳，有着更好的下水系统和灯光照明

:::details 使用方法

### 充值

1. 在微信小程序 呱呱物联 注册
2. 下载[慧新易校 APP](../digital/app#慧新易校)，在大厅中选择 宣城浴室充值
3. 输入第一步注册的手机号进行充值

### 使用

- 手机扫码
  - 打开微信小程序 呱呱物联扫描开关上方的二维码
- 校园卡刷卡
  - 需要预先绑定
- 洗浴码
  - 在呱呱物联小程序上设置好后，在水控机上输入洗浴码即可

:::

:::details 计费标准
预扣款 5 元，按**热水水量**计费，貌似比原来的标准略贵一点点

最热档最大水量 30 秒约 0.1 元^[需要验证]^

标称热水价格：25 元/吨[^2]
:::

:::details 旧的计费标准

刷卡后预扣款 1 元后即可出水，按 **0.03 元/10 秒** 计费，用水结束后再次刷卡即可离开

::::tip
夏天洗澡一般花费 2\~3 元，冬天可能花费 4\~5 元。洗澡时间因个人习惯而异，此处仅供参考
::::

## 洗衣机

:::danger

为了宿舍楼内的和睦和健康安全，**不要使用公用洗衣机洗鞋子/内裤/袜子**

:::

### 位置

:::tabs key:campus

== 屯溪路校区

大部分楼栋拥有公共洗衣房，配有洗衣机、烘干机。位于宿舍 1 楼。

== 翡翠湖校区

绝大部分宿舍每层楼均配有 2 个公共洗衣机，同时 1 楼有较大的公共洗衣房。

== 宣城校区

在每层浴室内共有两台台洗衣机/洗鞋机/烘干机，具体类型和位置可以在"海乐生活"小程序内查询

<AppBtn href="hfut_schedule://washing" text="在聚在工大 App 查看各楼层洗衣机运行情况"/>

:::

### 收费标准

:::tabs key:campus

== 合肥校区

通常为固定的常规洗 0.9 元/次，快速洗为 0.4 元/次。具体价格可以在“智慧笑联”APP 中查看。

== 宣城校区

价格时常有浮动且根据洗涤类型不同而有所差异，从最便宜的 0.6 元/次（快洗）到最贵的 1.6 元/次（慢洗）不等，具体价格可以在“海乐生活”小程序内查询

如果嫌弃公用的或有洁癖可以寝室一起买一台洗衣机，放在阳台，可联系安装师傅帮忙更换洗衣机专用水龙头

:::

## 公用吹风机

:::tabs key:campus

== 屯溪路校区

扫码使用，前 2 分钟免费，超过 2 分钟按 0.2 元/分钟计算

你可以在即将到达 2 分钟时结束订单，然后再次扫码使用从而实现免费使用

== 翡翠湖校区

免费

== 宣城校区

扫码使用，0.01 元/分钟
