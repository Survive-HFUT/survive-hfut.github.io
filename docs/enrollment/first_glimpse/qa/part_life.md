### 宿舍

::::::details

:::info

此节内容可详见[生活§宿舍](../../../life/dormitory/index)

:::

#### ❔ 宿舍是什么配置 / 几人间

:::tabs key:campus
== 屯溪路校区

== 翡翠湖校区

大部分四人间，极少为六人间

== 宣城校区

均为四人间，带阳台

:::

#### ❔ 宿舍怎么分配的

大部分是由校方进行分配，优先同班同专业，一般南北方搭配+一名本地生，具体情况可能因导员而异。少部分学院或导员允许学生自由组队

#### ❔ 本科四年是否需要搬宿舍

:::tabs key:campus

== 合肥校区

取决于学院，有些位于屯溪路校区的学院会要求学生在大二或者大三时搬到屯溪路校区

== 宣城校区

一般来说不需要，但当宿舍需要装修时可能会进行调整

:::

#### ❔ 可以申请换宿舍吗

可以，但是需要和导员申请

#### ❔ 最早什么时候可以进宿舍

报道当天

#### ❔ 床铺多大

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

195cm \* 85cm

== 宣城校区

1.9m \* 0.9m

:::

#### ❔ 可以装蚊帐和床帘吗

为方便军训期间查寝和检查卫生，原则上要等到军训结束后才能装

!!其实军训期间就有人装!!

#### ❔ 是上床下桌吗

是

#### ❔ 有空调 / 暖气吗

无统一供暖的暖气，但有空调，在冬天时可以开制热模式

需要以寝室为单位租赁空调，四年约 ￥1200。另需缴纳空调电费，按使用电量计费

#### ❔ 有独立卫浴吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

宿舍内只有洗手台和蹲便坑，淋浴间为公共浴室

== 宣城校区

没有，但是有带隔间和帘子的公共浴室，浴室内设有暖气片、储物柜、休息凳等设施

:::

#### ❔ 有洗衣机吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

有洗衣房

== 宣城校区

有公用洗衣机、洗鞋机、烘干机，也可自行购买洗衣机放在宿舍阳台

:::

#### ❔ 浴室热水供应时间

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

== 宣城校区

早上七点至凌晨十二点半

:::

#### ❔ 限电多少瓦

800W

#### ❔ 宿舍内能用电吹风 / 电热水壶吗

不可以，会跳闸

吹风机可以带到走廊或者浴室内的公用插座使用。宿舍楼内有饮水机，不需要自己烧水

#### ❔ 宿舍的饮用水要付费吗

:::tabs key:campus

== 合肥校区

宿舍楼内的直饮机需刷卡取水，一个机器同时提供开水和冷水（直饮水）

== 宣城校区

宿舍楼内的饮水机付费，食堂、教学楼、体育场、图书馆的饮水免费

:::

#### ❔ 晚上宿舍楼锁门吗 / 能夜出或晚归吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

宿舍楼 24:00 锁门（实际上未必会锁门）

== 宣城校区

宿舍楼锁门，若第二天为工作日 23:00 锁门，第二天为非工作日 24:00 锁门

若确定夜出或晚归时可以提前和宿管联系说明情况，到点时拨打电话让他帮忙开门

晚归时需填写晚归登记表，但是对评分评优评先的不会有什么影响

学校大门门禁 24h 可通行

:::

#### ❔ 晚上或放假期间会查寝吗

因导员和学院而异。学校一般不组织统一查寝，但是可能会要求生活委员统计离校情况

#### ❔ 可以到校外租房吗

需要和辅导员申请

:::warning

私自到校外租房居住==可能违反《合肥工业大学学生违纪处分办法》规定==

> 第二章 第二十条  
> （七）其他违反住宿管理规定的，视情节轻重，给予警告以上处分。[^4]

:::

### 外卖

::::::details

#### ❔ 取外卖点离宿舍近吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

正规外卖点在大北门小北门各一个，离宿舍楼约 3~5 分钟路程。（可以点到各个楼栋的旁边，学校栅栏处，但容易被偷，不推荐）

== 宣城校区

- 北区
  - 放在三号楼停车场靠马路一侧的外卖柜，离宿舍楼约 2~4 分钟路程
- 南区
  - 放在九号楼与十号楼之间的小路尽头的外卖柜，离宿舍楼约 3~6 分钟路程

:::

#### ❔ 能送至宿舍楼下吗

使用一些校园外卖平台可以直接送至宿舍楼和学校内各建筑楼下

美团、饿了么平台上标有==「校园送」==的商户可送至宿舍楼下

#### ❔ 大概需要多久才能送达

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

== 宣城校区

北门外小吃街商户的配送时间在 20~40min 不等，市区商户因学校离市中心较远，配送时间可能较长（>50min），天气恶劣时配送时间可能达到 1h 以上

:::

:::tabs key:campus

== 合肥校区

可以，但需要办市内牌照和校内牌照

### 校园网

::::::details

:::info

此节内容可详见[生活§校园网](../../../life/digital/network.md)

:::

#### ❔ 不办理校园流量卡或电话卡可以使用校园网吗

当然可以。这两个**没有任何关联**

**办理校园流量卡或电话卡也不会使抢课变得更快**，但是连校园网抢课会相对来说快一点

#### ❔ 一个账号能同时登录手机和电脑吗

不能，同一账号同时只能登录一台设备

可以让手机连校园网后开热点，或用 USB 共享网络给电脑

#### ❔ 限速限流吗

:::tabs key:campus

== 合肥校区

根据校园网套餐而定

免费的套餐限速 10Mbps，而最高的套餐（40 元/月）几乎不限速；无论使用的是哪种套餐均不限流

== 宣城校区

- 不限速，网速可以跑到 200Mbps 以上
- 限流，每月 200G，超出按 0.5 元/GB 付费，法定节假日和寒暑假免费

:::

#### ❔ 信号好吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

教学楼内信号尚可，宿舍楼内几乎没有校园网信号，只能插网线使用

13 号楼内只有无线网，没有网口

== 宣城校区

教学楼内信号均满格，宿舍楼内无线网因宿舍离 AP 的距离不同可能有所差异，但是有网线接口

:::

#### ❔ 晚上会断网吗

:::tabs key:campus

== 合肥校区

不断电不断网

== 宣城校区

- 若第二天为工作日（一般的周日到周四和放假的最后一天）
  - **23:00** - 次日 6:00 断电断网
- 若第二天为非工作日（一般的周五和周六、放假前一天以及放假期间）
  - **00:00** - 6:00 断电**不断网**

:::

#### ❔ 可以单独办理宽带吗

:::tabs key:campus
== 屯溪路校区

== 翡翠湖校区

可以

== 宣城校区

因未预留宽带管线接口，无法办理宽带

:::
