### 银行卡 / 学费缴交

::::::details

#### ❔ 会发银行卡吗

随录取通知书一同发放**一张 I 类中国农业银行储蓄卡**，主要用于代缴学费

#### ❔ 银行卡怎么激活

携带录取通知书、本人身份证和银行卡到任意一个中国农业银行网点办理激活手续

:::tip

- 部分网点可能要求持卡人年满 18 周岁、出示新生手册上的具体学费或其他资料，==因此建议将录取通知书袋子内的所有资料一并带上==
- 开学报到期间可在[大学生活动中心](../../campus/xc/activity_center.md)的缴费咨询处直接激活

:::

#### ❔ 银行卡有什么用

和普通的银行卡一样，除此之外可以于每年开学前提前将学费存入卡内等待统一批扣

#### ❔ 学费什么时候缴交

每学期开学之前，大约在八月底会统一批扣

#### ❔ 学费怎么缴交

为优化新生报到流程，减少学生和家长的排队等候过程，新生报到期间将不设集中缴费点,报到现场不受理现金缴纳各项费用，学生可以通过以下方式缴费：[^10][^11]

- **方式一：网上缴费**
  - 学生可以登录“合肥工业大学信息门户”点击“缴费平台”进行缴费
  - 关注“合肥工业大学财务处”微信公众号选择“微财务—缴费平台”进行缴费
- **方式二：中国农业银行统一代扣**
  - 学校会为每位新生办理一张中国农业银行 I 类卡，银行卡初始密码为“111111”。选择方式二缴费的学生，收到银行卡后，请自行前往任一农业银行网点办理卡片激活（激活银行卡需要本人携带身份证原件、银行卡，未满 18 周岁的需监护人陪同办理，监护人需出示身份证原件，相关监护关系证明如：户口本），并==将学费、住宿费足额存入农业银行卡内==，学校将委托银行在 2026 年 8 月底进行代扣。

### 学号

::::::details

#### ❔ 学号 / 工号是什么

是以入学年份开头的 10 位数字，前四位为入学年份，第五和第六位为身份标识（本科生为`21`），后四位为顺序号。如`2026210001`，表示 2026 年入学的本科生

对于教职工，前四位为入职年份

#### ❔ 学号在哪查

在学院群/系群内由导员发布

### 报到

::::::details

#### ❔ 什么时候报道

:::tabs key:campus

== 合肥校区

|          本科生          |     少数民族预科班     |
| :----------------------: | :--------------------: |
| 2026 年 8 月 28 日-29 日 | 2026 年 9 月 2 日-3 日 |

[^10]

== 宣城校区

2026 年 8 月 26 日至 27 日 8:00 至 18:00[^11]

:::

#### ❔ 延期报道应该怎么做

如因特殊原因不能按期报到者，须在指定时间之前通过新生官方群向学院提交请假手续（含书面请假申请，以及相关证明材料）。请假时间不得超过两周，逾期则视为自动放弃入学资格[^10][^11]

#### ❔ 我该去哪个校区报到

取决于录取通知书中或填报志愿所选的校区。若为合肥校区，则到位于合肥的[翡翠湖校区](../../campus/fch/)报到；否则在[宣城校区](../../campus/xc/)报到[^10][^11]

#### ❔ 流程是什么样的

1. 跟随工作人员指引到达报到现场，将准考证、报到证、照片交给工作人员，领取新生礼包（综合信息单、校园卡、学生手册、院系相关介绍或文创等）[^3]
2. 携带综合信息单领取军训服[^3]
   - 建议当场试穿，尺寸不符或破损可退换
   - 后续因发放完毕无法更换
3. 到校医院体检[^3]
4. 接受集体教育（参观校史馆、开展年级大会等）

#### ❔ 体检有什么注意事项吗

需要抽血，且排队等待时间比较长

#### ❔ 宿舍是什么配置 / 几人间

:::tabs key:campus
== 屯溪路校区

== 翡翠湖校区

大部分四人间，极少为六人间

均为四人间，带阳台

#### ❔ 宿舍怎么分配的

大部分是由校方进行分配，优先同班同专业，一般南北方搭配+一名本地生，具体情况可能因导员而异。少部分学院或导员允许学生自由组队

#### ❔ 本科四年是否需要搬宿舍

:::tabs key:campus

== 合肥校区

取决于学院，有些位于屯溪路校区的学院会要求学生在大二或者大三时搬到屯溪路校区

== 宣城校区

一般来说不需要，但当宿舍需要装修时可能会进行调整

:::

#### ❔ 可以申请换宿舍吗

可以，但是需要和导员申请

#### ❔ 最早什么时候可以进宿舍

报道当天

#### ❔ 床铺多大

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

195cm \* 85cm

== 宣城校区

1.9m \* 0.9m

:::

#### ❔ 可以装蚊帐和床帘吗

为方便军训期间查寝和检查卫生，原则上要等到军训结束后才能装

!!其实军训期间就有人装!!

#### ❔ 是上床下桌吗

是

#### ❔ 有空调 / 暖气吗

无统一供暖的暖气，但有空调，在冬天时可以开制热模式

需要以寝室为单位租赁空调，四年约 ￥1200。另需缴纳空调电费，按使用电量计费

#### ❔ 有独立卫浴吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

宿舍内只有洗手台和蹲便坑，淋浴间为公共浴室

== 宣城校区

没有，但是有带隔间和帘子的公共浴室，浴室内设有暖气片、储物柜、休息凳等设施

:::

#### ❔ 有洗衣机吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

有洗衣房

== 宣城校区

有公用洗衣机、洗鞋机、烘干机，也可自行购买洗衣机放在宿舍阳台

:::

#### ❔ 浴室热水供应时间

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

== 宣城校区

早上七点至凌晨十二点半

:::

#### ❔ 限电多少瓦

800W

#### ❔ 宿舍内能用电吹风 / 电热水壶吗

不可以，会跳闸

吹风机可以带到走廊或者浴室内的公用插座使用。宿舍楼内有饮水机，不需要自己烧水

#### ❔ 晚上宿舍楼锁门吗 / 能夜出或晚归吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

宿舍楼 24:00 锁门（实际上未必会锁门）

== 宣城校区

宿舍楼锁门，若第二天为工作日 23:00 锁门，第二天为非工作日 24:00 锁门

若确定夜出或晚归时可以提前和宿管联系说明情况，到点时拨打电话让他帮忙开门

晚归时需填写晚归登记表，但是对评分评优评先的不会有什么影响

学校大门门禁 24h 可通行

:::

#### ❔ 晚上或放假期间会查寝吗

因导员和学院而异。学校一般不组织统一查寝，但是可能会要求生活委员统计离校情况

#### ❔ 可以到校外租房吗

需要和辅导员申请

:::warning

私自到校外租房居住==可能违反《合肥工业大学学生违纪处分办法》规定==

> 第二章 第二十条  
> （七）其他违反住宿管理规定的，视情节轻重，给予警告以上处分。[^4]

### 外卖

::::::details

#### ❔ 取外卖点离宿舍近吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

正规外卖点在大北门小北门各一个，离宿舍楼约 3~5 分钟路程。（可以点到各个楼栋的旁边，学校栅栏处，但容易被偷，不推荐）

== 宣城校区

- 北区
  - 放在三号楼停车场靠马路一侧的外卖柜，离宿舍楼约 2~4 分钟路程
- 南区
  - 放在九号楼与十号楼之间的小路尽头的外卖柜，离宿舍楼约 3~6 分钟路程

:::

#### ❔ 能送至宿舍楼下吗

使用一些校园外卖平台可以直接送至宿舍楼和学校内各建筑楼下

美团、饿了么平台上标有==「校园送」==的商户可送至宿舍楼下

#### ❔ 大概需要多久才能送达

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

== 宣城校区

北门外小吃街商户的配送时间在 20~40min 不等，市区商户因学校离市中心较远，配送时间可能较长（>50min），天气恶劣时配送时间可能达到 1h 以上

### 校园网

::::::details

:::info

此节内容可详见[生活§校园网](../../life/digital/network.md)

#### ❔ 限速限流吗

:::tabs key:campus

== 合肥校区

根据校园网套餐而定

免费的套餐限速 10Mbps，而最高的套餐（40 元/月）几乎不限速；无论使用的是哪种套餐均不限流

== 宣城校区

不限速，网速可以跑到 200Mbps 以上

限流，每月 200G，超出按 0.5 元/GB 付费，法定节假日和寒暑假免费

:::

#### ❔ 信号好吗

:::tabs key:campus

== 屯溪路校区

== 翡翠湖校区

教学楼内信号尚可，宿舍楼内几乎没有校园网信号，只能插网线使用

13 号楼内只有无线网，没有网口

== 宣城校区

教学楼内信号均满格，宿舍楼内无线网因宿舍离 AP 的距离不同可能有所差异，但是有网线接口

:::

#### ❔ 晚上会断网吗

:::tabs key:campus

== 合肥校区

不断电不断网

== 宣城校区

- 若第二天为工作日（一般的周日到周四和放假的最后一天）
  - **23:00** - 次日 6:00 断电断网
- 若第二天为非工作日（一般的周五和周六、放假前一天以及放假期间）
  - **00:00** - 6:00 断电**不断网**

:::

#### ❔ 可以单独办理宽带吗

:::tabs key:campus
== 屯溪路校区

== 翡翠湖校区

可以

== 宣城校区

因未预留宽带管线接口，无法办理宽带

#### ❔ 价格怎么样/吃得饱吗

日常午晚餐消费约 8~15 元，几乎所有窗口均可免费加饭，量大管饱

#### ❔ 干净吗/异物多吗

大部分还是算挺干净的，很少吃出异物

#### ❔ 怎么消费/支持微信或支付宝吗

刷校园卡支付，几乎所有窗口都不支持移动支付（[宣区北区三楼谦谦餐厅](../../campus/xc/cafeterias/north#谦谦餐厅)总是支持移动支付）

开学期间或有重大活动期间（如毕业典礼、校园开放日、研究生招生考试），为方便校外人员就餐，大部分窗口支持刷卡支付和移动支付

### 第二课堂

::::::details

:::info

详见[学习§第二课堂](../../academics/practice/second.md)

:::

#### ❔ 这是什么

第二课堂是学校为了学生全面发展要求的活动，主要注重的是学生的课外发展；与之相对的是第一课堂，即日常课内的学习

#### ❔ 驾照可以加学分吗

不加学分，但是可以加第二课堂的技能星星

:::tip

入学后取得的驾驶证才计入，因此你可选择在该暑假考完科目一至三，剩余的留至大一寒假考

:::
